# Streamlit Mini Projects

A collection of small projects built with **Streamlit** to practice Python and data apps. Each project is deployed on Streamlit Community Cloud.

## Projects

- [Fibonacci](https://project-fibonacci.streamlit.app/)
- [Caesar Cipher](https://project-cesar.streamlit.app/)
- [Vigenère Cipher](https://project-vigenere.streamlit.app/)

> Apps on Streamlit Community Cloud go to sleep after a period of inactivity. If you see a "wake up" button, click it and wait a few seconds.

## Tech stack

- Python
- Streamlit

## Running locally

Requires Python 3.9 or newer.

```bash
git clone https://github.com/brunocmg/streamlit.git
cd streamlit
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run <path-to-app>.py
```
